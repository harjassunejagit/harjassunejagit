### 🔭 Currently Cooking

> **🛡️ Cross-Repository Vulnerability Propagation Predictor** — *in progress*
>
> Dependabot and Snyk flag *every* vulnerable dependency, which leads to alert fatigue. This tool asks a sharper question: **can the vulnerable code actually be reached from your code?**
> A fine-tuned **CodeBERT** model maps CVEs to the exact functions they affect, a **Tree-sitter** call graph with taint analysis checks reachability, and a **CVSS + EPSS** weighted score ranks what really matters. It ships as a **GitHub Action** with git-diff-aware incremental updates.
