## 🔭 Currently Building

> ### 🛡️ Cross-Repository Vulnerability Propagation Predictor
> Tools like Dependabot and Snyk flag **every** vulnerable dependency, so developers drown in alerts. This project asks a sharper question: **can the vulnerable code actually be reached from your code?**
>
> **CodeBERT** pinpoints the functions a CVE affects → a **Tree-sitter call graph** with taint analysis checks reachability → a **CVSS + EPSS** score ranks what truly matters. Ships as a **GitHub Action** with incremental, diff-aware updates.
>
